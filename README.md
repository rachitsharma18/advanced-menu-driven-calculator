Advanced Menu Driven Project

📌Description

This is a Python-based Advanced Menu Driven Project developed during my Class 12 studies. The project uses a menu-driven approach where users can choose different options from a menu and perform various operations.
The project was created to practice Python programming fundamentals and improve problem-solving skills.


🛠️ Technologies Used
Python


📖 Concepts Used

* Variables and Data Types
* Input and Output Operations
* Conditional Statements (if-else)
* Loops (for, while)
* Functions
* Menu Driven Programming

▶️ How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run the Python file:

```bash
python main.py
```

🎯Purpose of the Project

* To understand Python programming concepts.
* To learn menu-driven program design.
* To improve logical thinking and coding skills.
* To gain hands-on experience with Python.


This project was developed as a learning project during Class 12 and demonstrates the use of Python fundamentals through a menu-driven program.
